# API Documentation

This directory contains reference notes and schema specifications for SerpApi's `google_maps_reviews` engine.

## SerpApi Google Maps Reviews Engine

- Endpoint: `https://serpapi.com/search.json`
- Engine: `google_maps_reviews`
- Key parameter: `data_id` (Google Maps feature identifier)
- Pagination token: `serpapi_pagination.next_page_token`
- Quota: 1 search credit per page request
